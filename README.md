# Cr-er-un-Serveur-Bookstak-sur-Raspberry-Pi-4
Ce projet documente comment transformer un Raspberry Pi 4 en un vrai serveur web accessible depuis n'importe où dans le monde, 24 heures sur 24 et 7 jours sur 7.  L'application installée s'appelle BookStack : c'est un wiki personnel, comme une encyclopédie privée,
